# Pelops Assistant for Android

Prototipo Android inicial con burbuja flotante, conversación local, historial guardado en el teléfono, dictado por voz y lectura en voz alta.

## Estado real
- Incluye: app Android, burbuja flotante movible, historial local y controles de voz.
- Todavía no incluye: conexión a un modelo de IA, memoria en la nube, ejecución autónoma de tareas ni sincronización entre dispositivos.
- No se requiere una API key para probar esta versión. No introduzcas claves secretas dentro del APK.

GitHub Actions compila el APK de lanzamiento automáticamente al subir cambios y lo publica en un release.
